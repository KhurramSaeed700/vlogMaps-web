# Web project Codex context

This is the canonical project-local `.codex` directory for VlogMaps web.
Store project-specific Codex configuration and supporting context here; keep reusable skills in `../.agents/skills/`.

Shared project instructions live in `../AGENTS.md`. Before web work, inspect both this directory and `../.agents/` for relevant context. Do not copy global user configuration, credentials, or API keys here.

## User working preferences

- Carry authorized tasks through to completion, including appropriate verification. Do not stop at a plan, partial implementation, or an offer to continue when the remaining work is already authorized.
- Continue independently through routine decisions and recoverable failures. Pause only when required approval or genuinely missing information blocks further progress; explain the concrete blocker and complete independent work first.
- Do not ask for the same approval again unless the action or permission scope materially changes.
- Do not automatically commit, push, or deploy after changes. Do so only when requested.

- Ground travel must follow available road routes by default on both Watch and Edit. Use thin orange dotted lines only for off-road sections or gaps with no usable road route, preserving the road portion of mixed journeys. Keep flight paths separate.
